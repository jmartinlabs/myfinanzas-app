# Ui guidelines

## Applicability — UNDECIDED
Determine whether a graphical interface exists. For non-visual projects record
“Not applicable” with the reason; do not impose web or visual conventions.
For visual projects confirm and document:
- Visual direction and reusable components.
- Tokens: colors, typography, spacing and radii, with actual values after approval.
- Responsive layout rules and supported viewports.
- Keyboard access, focus, semantic structure, contrast and assistive technology checks.
- Empty, loading, error and disabled states for each relevant interaction.
- Screenshot evidence at 390px and 1440px for web acceptance flows.
These are initialization instructions, not approved design decisions.
